## 📌 Overview

This repository contains the projects completed as part of my **Artificial Intelligence Internship at CodSoft**.

The internship involved implementing practical Artificial Intelligence concepts through multiple projects covering **rule-based systems, game-playing AI, computer vision, and natural language processing**.

I selected and completed the following three tasks:

1. **Task 1 - Rule-Based Chatbot**
2. **Task 2 - Tic-Tac-Toe AI**
3. **Task 3 - Image Captioning**

Each task is maintained in a separate folder with its own source code, documentation, and required files.

---

## 🎯 Internship Objectives

The main objectives of these projects are:

- Apply Artificial Intelligence concepts to practical problems.
- Understand and implement different AI techniques.
- Develop Python-based AI applications.
- Work with algorithms and pretrained AI models.
- Understand the interaction between computer vision, NLP, and AI.
- Build well-documented and reproducible projects.
