# Rule-Based Chatbot

## 📌 Project Overview

This project is a simple rule-based chatbot developed using Python.

The chatbot interacts with users through the command line and provides predefined responses based on specific keywords and phrases entered by the user.

The project demonstrates the basic concept of conversational AI using rule-based logic and conditional statements.

This project was developed as part of the **CodSoft Artificial Intelligence Internship – Task 1**.

---

## 🎯 Objectives

- Build a simple conversational chatbot.
- Implement predefined responses for common user inputs.
- Understand rule-based conversational systems.
- Use Python conditional statements for response generation.
- Handle unknown user inputs gracefully.
- Create an interactive command-line chatbot.

---

## 🛠️ Technologies Used

- Python 3.10
- Conditional Statements
- String Processing
- Command-Line Interface

No external Python libraries are required.

---

## ✨ Features

- 👋 Greeting responses
- 🤖 Chatbot identity responses
- 😊 "How are you?" responses
- 🆘 Help command
- 🐍 Python-related response
- 🧠 Artificial Intelligence explanation
- 🎓 CodSoft internship response
- 🙏 Thank-you response
- 👋 Goodbye functionality
- ❓ Unknown-input handling
- ⌨️ Interactive command-line interface
